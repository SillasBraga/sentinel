# Política de segurança

Não publique vulnerabilidades em issues abertas.

Enquanto o repositório não tiver um canal privado de reporte configurado no GitHub, entre em contato diretamente com o mantenedor do projeto. Antes de tornar o repositório público, configure **Security advisories** e um contato seguro nesta página.

Inclua no relato apenas o necessário: versão afetada, impacto, passos mínimos para reprodução e uma sugestão de correção, se houver. Não envie dados reais de usuários, tokens ou chaves.

Consulte [docs/SECURITY.md](docs/SECURITY.md) para o modelo de segurança, checklist operacional e limites de responsabilidade.
