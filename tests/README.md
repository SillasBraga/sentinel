# Testes unitários

Os testes Vitest deste diretório cobrem regras puras que não precisam de navegador ou banco real: permissões, cálculo de risco e analytics de recuperação.

```bash
npm test
npm run test:watch
```

Testes de RLS ficam em `supabase/tests`; fluxos de navegador ficam em `e2e`. Veja [docs/TESTING.md](../docs/TESTING.md).
